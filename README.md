# Raio X | Exemplos Global Brand

[Abrir a página principal](https://mendesadss.github.io/exemplo/).

A página inicial reúne as pesquisas de iluminação sem fio e presentes personalizados para pets. Cada card abre a pesquisa completa em uma nova guia.

O pacote contém páginas, imagens, vídeos, comparativos e fontes vinculadas. As pesquisas mantêm os dados e as datas de coleta originais, com a paleta clara aprovada.

Site estático publicado pelo GitHub Pages a partir da branch `main`, pasta raiz. Nenhum serviço do domínio mendesadss.com é necessário.
